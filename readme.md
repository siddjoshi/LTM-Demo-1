# Tic Tac Toe

A simple, dependency-free Tic Tac Toe game that runs in any modern web browser.

## How to play

Open `index.html` directly in your browser, or serve the folder locally:

```bash
# from the repository root
python3 -m http.server 8000
# then visit http://localhost:8000 in your browser
```

## Features

- Two-player local play (X and O)
- Win and draw detection with winning-line highlight
- Score tracking across rounds
- "New Round" and "Reset Scores" controls
- Responsive layout that works on desktop and mobile
